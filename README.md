# AlphaForge: Neuro-Symbolic Evolutionary Alpha Discovery Engine

Quantitative research framework combining LLM hypothesis generation with Genetic Programming to discover orthogonal cross-sectional alpha factors for US Equities.

## Features
- Zero Look-Ahead & Execution Bias (Open t+1 to Open t+2)
- Sandboxed AST & Parsimony-Penalized Genetic Evolution
- Deflated Sharpe Ratio (DSR) & Combinatorial Purged Cross-Validation (CPCV)

## Run
1. pytest -v
2. python run_discovery.py
3. streamlit run app/dashboard.py
